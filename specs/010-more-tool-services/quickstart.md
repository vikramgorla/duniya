# Quickstart

Local: Bots → bot → Tool services → Add → type *Local* → package `@modelcontextprotocol/server-sequential-thinking`
→ Save → Install → Discover tools. Headers: Advanced → `X-API-Key: ${MY_KEY}`. Own OAuth app: Advanced → client ID,
secret `${MY_CLIENT_SECRET}`, register the shown redirect URL with the service, then Connect.
