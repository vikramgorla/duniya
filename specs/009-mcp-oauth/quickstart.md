# Quickstart

1. Bots → your bot → Tool services → add `https://www.panduga.ch/mcp` → **Check** (switches to Sign in).
2. **Connect** next to Organizers → sign in on panduga.ch → back on the bot, "Connected".
3. Optionally **Connect** Participants with a member account.
4. **Discover tools**, tick tools per role, Save, try the test console.
